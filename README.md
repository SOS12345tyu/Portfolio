# Sara Hawarneh Engineering Portfolio

Editable static portfolio website.

## Editing
Most website text is in `content.js`.
- Change text, metrics, project descriptions, links, and image paths there.
- Visual styling is in `styles.css`.
- Page structure is in `index.html`.

## Publishing
This repository is designed for GitHub Pages. In GitHub open **Settings > Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
